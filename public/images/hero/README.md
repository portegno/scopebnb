# Hero background photos

Drop your astrophotos here (JPG/WEBP, wide ~16:9, e.g. 2200×1240) and list them
in `src/data/heroImages.ts`:

```ts
{ src: "/images/hero/m42.jpg", alt: "Orion Nebula — shot from our rig" },
```

They cross-fade slowly on the home hero. Until you add files, the hero seeds
real DSS2 sky imagery from the CDS as placeholders.
